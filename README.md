# Puffways

Puffways is a React Native navigation app concept that focuses on quieter routes, local knowledge, and community-reported hazards.

The idea is to help drivers avoid busy roads and favour lower-stress, back-road alternatives, while still supporting the community features people expect from modern navigation apps.

## Features

- Quiet-route optimization
- Community alerts for police, cameras, hazards, roadworks, and incidents
- Traffic-aware route suggestions
- Route cards with ETA and route style
- Fast local navigation experience for Android and iOS

## Tech stack

- React Native
- TypeScript
- Expo
- React Navigation
- react-native-maps
- Expo Location

## Getting started

1. Install dependencies:
   npm install
2. Start Metro bundler:
   npm start
3. Run on Android:
   npm run android
4. Run on iOS:
   npm run ios

## Project structure

- `src/screens` – app screens
- `src/navigation` – navigation setup
- `src/components` – reusable UI components
- `src/services` – route and map logic
- `src/types` – TypeScript shared types
- `src/data` – sample route/hazard data

## Notes

This is a starter project intended for you to continue building and customise. The route logic is designed around the key concept of the app: actively avoiding busy roads where practical.
